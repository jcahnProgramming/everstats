Retention rule

Keep the last 14 nightly backups plus the first of each month. Backups made by hand are kept 30 days. Backups hold accounts and settings only — never Blizzard data older than the retention window.

Back up by hand

ssh tower cd <deploy folder> docker compose exec app npm run backup -- --label manual
Writes a verified copy next to the nightly ones. “Back up now” runs the same command.
