# Transmog

Transmog tracker with the catalog module: overall completion, slot picker with per-slot bars, filters (slot, collected/missing, armour type, quality, source), Head slot grid with a missing tile selected, detail pane with source line and Wowhead fallback, currently worn transmog list. Phone: chip slot picker, detail as a bottom sheet.

Screenshots: `screenshots/{desktop,phone}-{forever,alliance,horde}.png`. Open `index.html?theme=alliance|horde`.
