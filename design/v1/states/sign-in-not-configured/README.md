# Sign-in not configured yet

**When:** OAuth keys not set (or accounts disabled).

**Appears on:** Sign-in page; top-bar “Sign in” still shown and leads here; settings link methods disabled.

**Design:** Warning note “Accounts aren’t switched on yet…”, all provider buttons disabled with “Not configured”, passkey “Needs an account first”, back to search. Owner-only hint names the missing key.

Mockup: `index.html` (open with `?theme=alliance` / `?theme=horde`). Screenshots: `desktop-{forever,alliance,horde}.png` (1440px) and `phone-{forever,alliance,horde}.png` (390px).
