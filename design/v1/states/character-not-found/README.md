# Character not found

**When:** Lookup returned nothing.

**Appears on:** Character page (direct URL or search). Top-bar search suggestions show a one-line version: “Not found — characters appear from level 10, after logging out.”

**Design:** Explains honestly that Blizzard only lists characters from **level 10, after logging out**; two tips; search box prefilled with the query; “Search again”.
