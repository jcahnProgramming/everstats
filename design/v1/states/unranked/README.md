# Unranked — grading opens at N tracked characters

**When:** Ruleset below the admin minimum population.

**Appears on:** Character page overall tier + every category tier; guild roster tier column; leaderboards index population line; leaderboard tier column. N comes from Admin › Grading.

**Design:** Large dashed-feeling unranked badge “–”, ruleset tag, explanation, progress bar toward N (`--es-warning`). Small badges show “–”. Leaderboards themselves still work.

Mockup: `index.html` (open with `?theme=alliance` / `?theme=horde`). Screenshots: `desktop-{forever,alliance,horde}.png` (1440px) and `phone-{forever,alliance,horde}.png` (390px).
