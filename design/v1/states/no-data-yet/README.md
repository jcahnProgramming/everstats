# Empty leaderboard — no data yet

**When:** Statistic is tracked for this ruleset but every value is zero / nobody qualifies.

**Appears on:** Single leaderboard; leaderboards index mini board; home featured boards; character stat row rank pill (“board opens…”).

**Design:** Keeps the table header, then a **dashed** empty box: “No data yet” + when it was checked. Neutral surface. Contrast with no-coverage below.

Mockup: `index.html` (open with `?theme=alliance` / `?theme=horde`). Screenshots: `desktop-{forever,alliance,horde}.png` (1440px) and `phone-{forever,alliance,horde}.png` (390px).
