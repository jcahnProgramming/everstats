# Generating

The preview is dimmed with a spinner and a "Generating your card…" pill (`aria-busy`). Download and Copy image are disabled; Copy link still works.

Appears in: the card maker, from every entry point. Built on v1 (top bar, footer, `.panel`, `.seg`, `.toggle`, `.btn`, `.note`, `.toast`) and v2 (player inline badge in the header). The preview images are the example renders in `../../examples/` and follow the selected theme. Open `index.html?theme=alliance|horde`. Screenshots: `screenshots/{desktop,phone}-{theme}.png`.
