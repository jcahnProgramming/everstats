# Share toasts

These use v1's `.toast` component.

| Variant | Message |
|---|---|
| `ok` | Image copied |
| `ok` | Link copied |
| default | Download started (shows the file name) |
| `ok` | Saved as default |
| `warn` | Your browser blocked copying images → use Download PNG |
| `err` | Couldn't generate the image → Try again (your choices are kept) |

Placement, stacking and dismissal are the same as v1.

Live: `gallery/components.html` · `gallery/components-<theme>.png`. Styles: `card-maker.css` (only `var(--es-*)`).
